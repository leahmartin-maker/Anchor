# 🎉 8thwall is Now Open Source - Updates Complete!

## What Changed?

8thwall transitioned from a hosted service to a **completely open-source, free platform** at **8thwall.org**.

### Before (Hosted Platform)
- ❌ Required login to 8thwall.com console
- ❌ Need API key/license
- ❌ Monthly subscription ($0-$99+)
- ❌ Hosted only on 8thwall servers

### Now (Open Source)
- ✅ **No login required**
- ✅ **No API key needed**
- ✅ **Completely free** (MIT License)
- ✅ **Deploy anywhere** (Vercel, GitHub Pages, your server, etc.)
