## Getting Started (No Setup Needed!)

The good news? **The packages are already installed in your project.**

Your app automatically uses 8thwall's open-source XR Engine via npm packages.

### To verify it's working:

1. Run your dev server:
   ```bash
   npm run dev
   ```

2. Open in browser: http://localhost:5173

3. Open DevTools (F12) → Console

4. You should see AR initializing (no errors about licenses)

5. Point camera at an image/mural → AR tracking should work

---

## Optional: Download Desktop App

If you want the visual editor (8th Wall Desktop), you can download it:

1. Go to https://8thwall.org/downloads
2. Download for Mac or Windows
3. Install and run
4. Create 3D scenes or export projects

**But for your React web app, you don't need this** — everything works via npm packages.

## Troubleshooting

### AR not working?
- ✅ Check camera permissions in browser
- ✅ Make sure image is well-lit
- ✅ Try pointing at a photo/magazine
- ✅ Check browser console (F12) for errors

### Image tracking not recognizing mural?
- ✅ Ensure image is high contrast and distinctive
- ✅ Good lighting is important
- ✅ Try multiple angles
- ✅ Check console for any XR errors
